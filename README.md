# Nomadic Traveler — Global Travel Tracker

Production-ready monorepo scaffold for the Nomadic Traveler travel tracking and discovery platform.

## Stack
- Web: Next.js + TypeScript + Tailwind CSS
- API: Laravel 12 + PHP 8.3
- Database: PostgreSQL/MySQL compatible schema
- Maps: GeoJSON/SVG-ready
- Auth: Laravel Sanctum-ready
- Deployment: Docker + GitHub Actions-ready

## Modules
- 64 Bangladesh district tracker
- 195-country world tracker
- Traveler profiles
- Saved travel history
- Trip planner
- Hidden gems
- Reviews
- Quiz / leaderboard / badges
- PNG/JPG/PDF export
- Admin moderation
